# Shared research and dataset material

The same research/dataset folder was included in both uploaded phase archives. It is kept once here to avoid unnecessary repository duplication.

- `notes/`: dataset plan, literature matrix and research summary.
- `datasets/sms/`: supplied SMS dataset package, helper scripts and analysis PDFs.
- `datasets/url/`: the supplied PhiUSIIL phishing URL CSV.
- `papers/`: reports and research references included in the source archives.
- `training_scripts/`: optional model-training scripts and their training requirements.

The Streamlit apps load the supplied model files at runtime; they do not train models on startup. Dataset and paper reuse must follow each source's license and citation requirements.
